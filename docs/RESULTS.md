## Known limitations

The full list is in `GROUND-TRUTH.md` under "Known limitations". The short version, so it isn't buried:

- No tool detects the FreeRTOS fork, bomwerk included.
- bomwerk reports cJSON as `cjson-prebuilt` with no version, because the header only has the version as three numbers.
- bomwerk's CPE for FreeRTOS keeps the `v` in `V11.1.0`, which NVD won't match.

- `web/package-lock.json` is where the other tools should match or beat bomwerk.
